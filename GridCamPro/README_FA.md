# GridCam Pro - راهنمای نصب و اجرا

## پیش‌نیازها
- اندروید استودیو Arctic Fox یا جدیدتر
- JDK 17
- Android SDK 34
- دستگاه اندروید فیزیکی یا امولاتور با API 21+

## مراحل نصب و اجرا

### ۱. باز کردن پروژه در اندروید استودیو
1. اندروید استودیو را باز کنید
2. از منوی File گزینه Open را انتخاب کنید
3. پوشه GridCamPro را انتخاب کنید

### ۲. همگام‌سازی Gradle
1. پس از باز شدن پروژه، روی "Sync Now" کلیک کنید
2. صبر کنید تا تمام وابستگی‌ها دانلود شوند

### ۳. اجرای برنامه
1. دستگاه اندروید خود را وصل کنید یا امولاتور را راه‌اندازی کنید
2. روی دکمه Run (▶) کلیک کنید
3. مجوزهای دوربین و میکروفون را تأیید کنید

## ویژگی‌های کلیدی

### نسبت‌های تصویر پشتیبانی شده
- **۱:۱** - مناسب برای پست مربعی تلگرام/اینستاگرام
- **۹:۱۶** - مناسب برای ریلز و استوری
- **۴:۵** - مناسب برای پست عمودی
- **۱۶:۹** - مناسب برای ویدیوی افقی

### سیستم گرید
- خطوط گرید ۳×۳ قبل و در حین فیلم‌برداری نمایش داده می‌شوند
- خطوط در خروجی نهایی دیده نمی‌شوند
- قابلیت خاموش/روشن کردن گرید

### تنظیمات ساده
- تغییر دوربین (عقب/جلو)
- کنترل فلاش
- انتخاب نسبت تصویر
- تایمر (قابل توسعه)

## عکس‌برداری
1. نسبت تصویر مورد نظر را از منوی بالا انتخاب کنید
2. سوژه را در کادر گرید قرار دهید
3. دکمه دوربین را فشار دهید

## فیلم‌برداری
(در حال توسعه - فعلاً فقط عکس‌برداری فعال است)

## ذخیره‌سازی
- عکس‌ها در پوشه `Android/data/com.gridcam.pro/files` ذخیره می‌شوند
- فرمت: JPG برای عکس، MP4 برای ویدیو

## خطاهای رایج و راه‌حل‌ها

### خطای دسترسی دوربین
- مطمئن شوید مجوزهای لازم داده شده است
- در تنظیمات دستگاه، دسترسی دوربین را بررسی کنید

### خطای Gradle Sync
- اتصال اینترنت را بررسی کنید
- از منوی File گزینه "Invalidate Caches and Restart" را انتخاب کنید

### برنامه کرش می‌کند
- لاگ‌های Logcat را بررسی کنید
- مطمئن شوید دستگاه دارای دوربین است
